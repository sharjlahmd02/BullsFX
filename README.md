# BullsFX 

A modern trading portfolio platform built with React and Tailwind CSS. Explore structured investment plans, compare strategies side by side, and calculate your returns in real time.

🔗 **Live Demo:** [bullsfx.netlify.app](https://bullsfx.netlify.app/)

---

## Features

- **Investment Plans** — Browse multiple trading plans, each organized into clearly defined categories
- **Plan Comparison** — Compare any two plans side by side across key performance metrics
- **ROI Calculator** — Real-time calculator that computes:
  - Average Monthly ROI
  - Monthly Profit
  - And other financial metrics based on your input
- **Responsive UI** — Clean, data-friendly interface optimized for all screen sizes

---

## Tech Stack

- [React.js](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)

## Getting Started

### Prerequisites

Make sure you have **Node.js** installed. Download it from [nodejs.org](https://nodejs.org/).

### Installation

1. **Clone the repository**
```bash
   git clone https://github.com/sharjlahmd02/bullsfx.git
   cd bullsfx
```

2. **Install dependencies**
```bash
   npm install
```

3. **Start the development server**
```bash
   npm run dev
```

4. Open your browser and visit `http://localhost:5173`
